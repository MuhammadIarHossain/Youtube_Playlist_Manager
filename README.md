*Key Features :* <br>
   1. Create, Delete, Edit and Update any playlist.
   2. Search any video across the playlist.
   3. Add Youtube full playlist or multiple videos.
   4. Add video to any playlist.
   5. Delete video from playlist.
   6. Export all videos as a JSON file.
   7. Also export all videos links as a text file.
   8. Import any JSON file for adding playlist.
   9. Filter videos by "All, Favorite, Unwatched and Watched".
   10. Show Total numbers of playlist, videos and videos duration.
   11. Merge multiple playlist.
   12. Sort and change video view like grid or list.
   13. Mark video as watched.
   14. Add video in favorite tab. <br><br>

**How to use this website** <br>
- You need *[Youtube Data API v3 Key](https://developers.google.com/youtube/v3/docs)* for adding videos and playlist from youtube.com
- To add your API key click *Settings* icon on the top right side. After that a form will open. Write your API key in the input field.
